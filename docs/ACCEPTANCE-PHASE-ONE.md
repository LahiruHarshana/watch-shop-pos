# Phase One acceptance checklist

Use this during the shop demo. Check each item on the live system.

## Sales

- [ ] Search a product by name and by SKU (for example CR2032)
- [ ] Filter the checkout grid by category and move between pages
- [ ] Apply a line discount (flat and percent) and a cart discount
- [ ] Pay by cash (change shown), card, and bank transfer
- [ ] Stock drops after a completed sale
- [ ] Print a thermal receipt (58mm or 80mm from Settings)
- [ ] Download the PDF receipt
- [ ] Admin voids an invoice with a reason and stock returns

## Repairs

- [ ] Create a ticket with customer, watch, issue, and estimate
- [ ] Ticket ID is unique
- [ ] Move Pending → In progress → Ready for Collection → Delivered
- [ ] Print the claim token with terms
- [ ] Repair payment appears on the daily report separately from retail

## Inventory

- [ ] Categories include the six shop groups
- [ ] Battery size and brand can be saved on a product
- [ ] Admin adds stock and writes off damaged stock
- [ ] Cashier cannot open stock adjustments
- [ ] Dashboard shows low-stock alerts for admin
- [ ] Inventory filters (stock, brand, price, sort) and pagination work
- [ ] Admin can deactivate a product so it leaves the catalog

## Reports and staff

- [ ] Daily report splits retail and repair
- [ ] Open shift shows expected cash; close shift shows variance
- [ ] Admin creates, edits, deactivates, and resets a staff password
- [ ] Cashier cannot manage staff or void invoices
